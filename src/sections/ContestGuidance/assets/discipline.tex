\subsubsection{入场检查}
\begin{itemize}[leftmargin=5mm]
  \setlength{\itemsep}{0pt}
  \item 检查身份证件：护照、学生证、胸牌及现场所需通行证。
  \item 检查手机、智能手表、金属物品（钥匙）等是否按规定存放。
  \item 完整测试键盘、鼠标、显示器和座椅；如果有问题，立即联系工作人员。
\end{itemize}

\subsubsection{环境与 OJ 检查}
\begin{itemize}[leftmargin=5mm]
  \setlength{\itemsep}{0pt}
  \item 测试所有可能的提交方式(包括submit和domjudge提交)，找到题面与排行榜入口。
  \item 测试 \texttt{-fsanitize=address,undefined} 与 \texttt{-D\_GLIBCXX\_DEBUG}。
  \item 测试 \texttt{/usr/bin/time -v ./a} 能否显示内存占用。
  \item 测试编译器版本（比如c++20语法）以及 \texttt{bits/stdc++.h}、\texttt{pb\_ds}、\texttt{\_\_int128}、\texttt{\_\_float128} 和 \texttt{long double}。
  \item 检查 pragma target 是否 CE、代码长度限制，以及 NO-OUTPUT、OLE、MLE 的行为。
  \item 检查提交频率限制与队列规则，并测试 \texttt{clock()}、\texttt{make} 和本地/提交性能（NTT测速）。
  \item 测试printfile工具，观察从打印到送达的时间
\end{itemize}

\subsubsection{提交前检查}
\begin{enumerate}[leftmargin=5mm]
  \setlength{\itemsep}{0pt}
  \item 保存、编译、通过样例，并测试 $n=0/1$。
  \item 检查数组大小、时间与空间限制、实数输入、模数和整数类型。
  \item 检查 \texttt{init} 调用以及清空范围是 $(0,1,n)$、$m$ 还是 $n+1$。
  \item 检查答案正模、输出格式、多组输入是否完整读入。
  \item 检查流同步设置；不要在关闭同步后混用 C 与 C++ 输入输出。
  \item 加上需要用于验证假设的 \texttt{assert}，确认优化和指令集配置。
\end{enumerate}

\subsubsection{提交后检查}
\begin{enumerate}[leftmargin=5mm]
  \setlength{\itemsep}{0pt}
  \item 变量复用后是否忘记改回；多组输入的数组是否在正确范围和时机清空。
  \item 整数溢出、INF/-1 大小、浮点数 \texttt{eps}、零、\texttt{nan}/\texttt{inf}。
  \item 模板参数类型是否正确，例如 \texttt{pair<long long, int>} 被错误地从 \texttt{pair<int, int>} 构造。
  \item 离散化与二分的边界、\texttt{lower\_bound}/\texttt{upper\_bound} 的加减一，以及 \texttt{begin()}/\texttt{end()}。
  \item 自定义排序方向和严格弱序；构造非对称、非回文的反例。
  \item 复制代码后是否改全；shadow 变量；分类讨论、嵌套 \texttt{if} 和 \texttt{break} 位置。
  \item 图的边编号、单双向边和反向边权；几何的共线、重点、除零和旋转方向。
  \item 浮点数 \texttt{eps} 的量纲；二分、三分的迭代次数。
\end{enumerate}
